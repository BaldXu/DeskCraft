# DeskCraft 需求文档

> 由与用户的对话讨论整理而成，记录需求来源、功能与非功能需求。

## 一、需求来源（对话要点记录）

1. 用户看到小米手机桌面可添加第三方 App 组件，想自写一个 App，放上适合自己的组件，摆到手机桌面。
2. 用户熟悉 Flutter；虽知道这只会给安卓用，仍倾向 Flutter。后表示"是不是 Flutter 无所谓，反正基本都是 AI 来写" → 技术栈交 AI 定案。
3. 想要的组件：时钟、日历（嫌官方不好看、主题商店全要钱）、展示手机实时参数（温度、CPU 频率等）的组件。
4. 关键升级：灵感来自 **KWGT**——要做一个"属于自己的 KWGT"，即可视化组件编辑器（图层 + 公式 + 全局变量 + 触控 + 按需刷新），而非固定预置组件。
5. 用户手机 **有 root，Magisk 面具（非 KernelSU）**，纯自用，接受 root 方案。

## 二、用户画像 / 使用场景

- 唯一用户 = 开发者本人，中文界面。
- 手机：小米 + Magisk root。
- 桌面：MIUI/小米桌面，标准 Android AppWidget 支持。
- 追求实用、自给自足，不追求商业发布，不上架应用商店（debug 直装）。

## 三、功能需求

### 3.1 组件工坊（App 本体 / 管理器）
- 首页：所有可用组件卡片列表，每张带实时预览图（所见即所得）。
- 状态标识：已上桌/未上桌、最后刷新时间、数据是否正常。
- 组件配置页：主题色、背景样式（纯色/毛玻璃/渐变）、圆角、字体大小、深色模式；内容项开关（农历、节气、纪念日倒计时、24h 制、星期、日期）；尺寸提示（对应小米桌面几格）。

### 3.2 组件编辑器（KWGT 子集，V2 起核心）
- 图层画布 + 图层列表（z-index 堆叠），拖拽/缩放。
- 图层类型（V1 固定子集）：文本、形状（矩形/圆/线条）、进度条；V2 扩展：图表/图片/分组。
- 公式系统：`$...$` 表达式 —— 时间格式化、字符串拼接、条件 `$if()$`、四则运算、系统变量（时间/电池/温度/频率/内存/日历）、全局变量（GV）。
- 全局变量面板：定义颜色/文本/数字/开关/公式，多处引用。
- 触控：图层绑定点击动作（开 App / 开链接）；V2 更多动作。
- 按需刷新：公式声明秒级变量则秒刷，否则按需/分钟级（V2 精确化）。
- 预设导入导出（V2）。

### 3.3 桌面组件（V1 清单）
- **数字时钟**：TextClock 驱动，零功耗自动走秒，样式可配。→ 全链路验证组件。
- **日历**：月视图，今天高亮，农历/节气/纪念日，翻日即时更新（监听 DATE_CHANGED）。
- **系统监控 widget**：电池温度、CPU 实时频率（root 逐核心）、CPU 占用、内存；30s~1min 刷新；高温红色警示；点击跳悬浮窗。
- **实时监控悬浮窗**：秒级刷新，root 自动授权（免手动设置），半透明面板，可拖拽、调透明度、显示 CPU 频率/温度/电池温度/内存/网速。

### 3.4 root 相关
- libsu 接入，Magisk 授权一次后静默使用。
- 启动时自动执行白名单命令（Doze 白名单 + 后台运行允许 + 悬浮窗授权），免用户手动设置。
- root 状态页：授权状态、白名单是否生效、一键重试。

## 四、非功能需求

- 中文 UI。
- 纯本地、无服务端依赖（天气等外部数据源 V3 再议）。
- 低后台耗电：优先 TextClock / 按需刷新，秒级仅限悬浮窗。
- 深色模式适配。
- 组件/配置持久化，卸载重装数据不丢（或明确告知重置）。

## 五、约束与边界

- 桌面 widget 是原生 RemoteViews（平台规则），Flutter 无法直接渲染上桌 → 接受极薄原生壳。
- 秒级实时仅悬浮窗形态可行。
- 温度/CPU 频率依赖 root，不同机型 sysfs 路径不同，需真机实测，读不到则隐藏。
- 不发布上架，debug 直装即用。

## 六、验收口径（每个组件）
- 能添加到小米桌面并正确显示。
- 配置改动 → 桌面即时更新。
- 点击行为符合配置。
- 刷新频率与耗电符合预期。
